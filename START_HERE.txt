TEST FACTORY v2 시작하기
========================

1) 이 폴더를 VS Code 또는 Cursor에서 엽니다.

2) 설치합니다.
   npm install

3) 개발 서버를 실행합니다.
   npm run dev

4) 브라우저에서 확인합니다.
   서비스: http://localhost:3000
   제작 도구: http://localhost:3000/studio

현재 테스트팩
-------------
- 릴스핏: 공개
- 과일상: 공개
- 동물상: 초안 (Studio에서 편집 후 공개)

새 테스트 만들기
----------------
/studio에서 기존 테스트 복제 또는 빈 템플릿을 선택합니다.
질문·결과·이미지를 저장하면 content/test-packs와 public/images가 변경됩니다.

배포
----
npm run validate:packs
npm run typecheck
npm run build

git add .
git commit -m "새 테스트 추가"
git push

중요
----
- Studio는 로컬 전용입니다. Vercel에서는 열리지 않습니다.
- NEXT_PUBLIC_SITE_URL=https://testfit-black.vercel.app 를 Vercel 환경 변수로 설정하세요.
- 결과 URL 토큰은 암호화가 아니므로 민감정보를 질문에 넣지 마세요.
