# 과일상 성별별 독립 결과 이미지

과일상 8종 각각에 여성·남성 독립 일러스트를 연결합니다.

| 과일상 | 여성 이미지 | 남성 이미지 |
|---|---|---|
| 복숭아상 | `peach-female.webp` | `peach-male.webp` |
| 딸기상 | `strawberry-female.webp` | `strawberry-male.webp` |
| 사과상 | `apple-female.webp` | `apple-male.webp` |
| 체리상 | `cherry-female.webp` | `cherry-male.webp` |
| 레몬상 | `lemon-female.webp` | `lemon-male.webp` |
| 자몽상 | `grapefruit-female.webp` | `grapefruit-male.webp` |
| 포도상 | `grape-female.webp` | `grape-male.webp` |
| 수박상 | `watermelon-female.webp` | `watermelon-male.webp` |

모든 이미지는 768×768 WebP이며, 한 장 안에 한 명만 배치된 독립 일러스트입니다.
결과 페이지와 공유 이미지에서는 `contain` 방식으로 표시해 머리, 상반신, 과일 장식이 잘리지 않습니다.
