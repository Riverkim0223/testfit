릴스핏 결과 캐릭터 이미지 패치 적용 방법

1. 현재 실행 중인 Test Factory 프로젝트를 종료합니다.
2. 이 ZIP의 내용물을 프로젝트 루트(package.json이 있는 위치)에 풉니다.
3. 같은 이름의 파일은 덮어씁니다.
4. 다시 실행합니다.

npm 사용:
  npm run dev

pnpm 사용:
  pnpm dev

확인 주소:
  http://localhost:3000/tests/reels-fit

릴스핏 결과 8종에 서로 다른 캐릭터가 표시되며,
OG/피드/스토리 공유 이미지에도 같은 결과 캐릭터가 포함됩니다.
