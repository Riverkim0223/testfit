과일상 성별별 결과 이미지 패치 적용
=====================================

대상: 기존 Test Factory v1.2 프로젝트

1. 개발 서버를 Ctrl + C로 종료합니다.
2. 이 ZIP의 내용물을 프로젝트 루트(package.json이 있는 폴더)에 압축 해제합니다.
3. 같은 이름의 파일은 모두 덮어씁니다.
4. 다시 실행합니다.

   npm run dev

5. 브라우저에서 Ctrl + F5로 강력 새로고침합니다.

변경 사항
---------
- 과일상 시작 시 여성/남성 선택
- 과일상 8종 × 성별 2종 = 이미지 16장
- 선택한 성별의 결과 이미지가 결과 페이지와 공유 이미지에 적용
- 과일상 Test Pack 버전 2

새 패키지는 추가하지 않았으므로 npm install을 다시 실행할 필요가 없습니다.
기존 peach.webp 같은 단일 이미지 파일은 남아 있어도 사용되지 않으므로 문제 없습니다.
